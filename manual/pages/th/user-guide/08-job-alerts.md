## แจ้งเตือนงานใหม่คืออะไร

คุณบันทึกการค้นหาไว้ แล้วระบบส่งสรุปงานใหม่ที่ตรงตัวกรองให้เป็นรอบ ๆ ช่องทางหลักคืออีเมล และเปิดเพิ่มได้ทาง Telegram หรือ Webhook ต้องยืนยันอีเมลก่อน

**ก่อนเริ่ม**

- ยืนยันอีเมลของคุณแล้ว ดู [[getting-started]] ถ้ายังไม่ยืนยัน ระบบแสดง {{ui:"ยืนยันอีเมลก่อนจึงจะได้รับสรุปงาน"}}
- มีโปรเจกต์อย่างน้อยหนึ่งโปรเจกต์ การค้นหาที่บันทึกเก็บแยกตามโปรเจกต์
- ตั้งตัวกรองอย่างน้อยหนึ่งอย่าง เช่น คำค้นหรือเมือง ไม่เช่นนั้นปุ่ม {{ui:"บันทึกการค้นหานี้"}} กดไม่ได้

![การค้นหาที่บันทึกไว้และปุ่มแจ้งเตือน — วงหมายเลข 1 = ความถี่ของสรุป, 2 = ปุ่มอีเมล](/manual/alerts.th.png)

## วิธีแจ้งเตือนงานใหม่

1. เข้าเมนู “{{ui:"ค้นหางาน"}}”
2. ตั้งตัวกรองที่ต้องการ
3. คลิกปุ่ม {{ui:"บันทึกการค้นหานี้"}} ระบบแสดงหน้าต่าง {{ui:"บันทึกการค้นหา"}}
4. ระบุ {{ui:"ชื่อ"}}
5. เลือก {{ui:"ความถี่"}} เป็น {{ui:"ทุกวัน"}} หรือ {{ui:"ทุกสัปดาห์ (วันจันทร์)"}}
6. คลิกปุ่ม {{ui:"บันทึก"}} ระบบแสดงข้อความ {{ui:"บันทึกการค้นหาแล้ว"}} และการค้นหาอยู่ในรายการ {{ui:"การค้นหาที่บันทึกไว้"}}
7. ดูวันส่งรอบถัดไปที่ข้อความ {{ui:"สรุปครั้งถัดไป"}} ใต้ชื่อการค้นหา

เพิ่ม Telegram (ถ้าต้องการ)

1. เข้าเมนู “{{ui:"การตั้งค่า"}}” แล้วเลือก {{ui:"Webhook"}} การ์ด Telegram อยู่ในหน้านี้
2. คลิกปุ่ม {{ui:"เชื่อมต่อ Telegram"}} ระบบแสดงข้อความ {{ui:"รอการยืนยันใน Telegram กด Start ในแชตที่เปิดขึ้น"}}
3. เปิดลิงก์ที่ระบบแสดง
4. กด Start ในแชต Telegram
5. รอข้อความ {{ui:"เชื่อมต่อแล้ว"}}
6. กลับไปหน้าค้นหางาน แล้วคลิกปุ่มไอคอน Telegram ข้างการค้นหานั้นให้เปิดอยู่

เพิ่ม Webhook (ถ้าต้องการ)

1. เข้าเมนู “{{ui:"การตั้งค่า"}}” แล้วเลือก {{ui:"Webhook"}}
2. ระบุ {{ui:"URL ปลายทาง"}} (จำเป็นต้องระบุ)
3. เลือกเหตุการณ์ {{ui:"สรุปงานใหม่พร้อม"}}
4. คลิกปุ่ม {{ui:"เพิ่ม webhook"}} ระบบแสดง secret สำหรับตรวจลายเซ็น
5. คัดลอก secret ที่แสดง แล้วคลิกปุ่ม {{ui:"บันทึกแล้ว"}}
6. กลับไปหน้าค้นหางาน แล้วคลิกปุ่มไอคอนกระดิ่ง (push) ข้างการค้นหานั้นให้เปิดอยู่

## ข้อควรทราบ

- อีเมลสรุปส่งเวลา 08:00 น. สรุปนี้ไม่ใช่การสมัครงานและไม่ใช่คำแนะนำจาก AI เป็นเพียงรายการงานใหม่ที่ตรงตัวกรองของคุณ
- ปุ่มไอคอนข้างการค้นหาแต่ละรายการ ได้แก่ อีเมล กระดิ่ง (push) Telegram ส่งตัวอย่าง และถังขยะ เอาเมาส์ชี้เพื่อดูชื่อปุ่ม
- Webhook ใช้สำหรับระบบอื่นของคุณเอง หากไม่แน่ใจให้ข้าม ใช้เพียงอีเมลก็ได้
- ส่วน Telegram จะแสดงเมื่อเซิร์ฟเวอร์ตั้งค่าบอตไว้เท่านั้น
- ลิงก์ Telegram มีเวลาจำกัด ถ้าหมดอายุให้เชื่อมต่อใหม่
- URL ของ Webhook ต้องเป็น https และ secret แสดงครั้งเดียว ควรคัดลอกเก็บไว้
- บันทึกการค้นหาได้ไม่เกิน 10 รายการต่อโปรเจกต์ และเพิ่ม Webhook ได้ไม่เกิน 5 รายการ
- ถ้าโปรเจกต์ปิดการแจ้งเตือน จะไม่ได้รับสรุป เปิดได้ที่การตั้งค่าโปรเจกต์
- หยุดรับอีเมลได้จากลิงก์ในอีเมลโดยไม่ต้องเข้าสู่ระบบ
- การยกเลิกการเชื่อมต่อ Telegram ปิดการส่งทาง Telegram ในทุกการค้นหาที่บันทึกไว้

## ปัญหาที่อาจพบและวิธีแก้ไข

- ปัญหา: “ยืนยันอีเมลก่อนจึงจะได้รับสรุปงาน”
  วิธีแก้ไข: ยืนยันอีเมลตามขั้นตอนใน [[getting-started]]
- ปัญหา: “บันทึกได้สูงสุด 10 การค้นหาต่อโปรเจกต์”
  วิธีแก้ไข: ลบการค้นหาที่ไม่ใช้แล้ว
- ปัญหา: “ชื่อนี้ถูกใช้แล้ว”
  วิธีแก้ไข: ระบุชื่ออื่น
- ปัญหา: “ลิงก์หมดอายุแล้ว กดเชื่อมต่อใหม่อีกครั้ง”
  วิธีแก้ไข: คลิกปุ่ม {{ui:"เชื่อมต่อ Telegram"}} อีกครั้ง
- ปัญหา: “URL ต้องเป็น https และชี้ไปยังเซิร์ฟเวอร์สาธารณะ”
  วิธีแก้ไข: ระบุ URL แบบ https ที่เปิดจากอินเทอร์เน็ตได้
