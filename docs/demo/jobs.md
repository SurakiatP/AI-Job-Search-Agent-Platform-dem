# ตำแหน่งงานตัวอย่าง (ข้อมูลสมมติ)

ทุกตำแหน่งและบริษัทเป็นข้อมูลสมมติเพื่อการสาธิต ใช้คัดลอกไปวางในหน้า Saved jobs

## 1. Senior Frontend Developer — เหมาะมาก

- **บริษัท:** ตัวอย่างดิจิทัล จำกัด (ตัวอย่าง)
- **สถานที่:** กรุงเทพมหานคร (ไฮบริด)

**รายละเอียดงาน**

เรากำลังมองหา Senior Frontend Developer เพื่อพัฒนาเว็บแอปแดชบอร์ดสำหรับลูกค้าองค์กร
- พัฒนาและดูแลเว็บแอปด้วย React, TypeScript และ Next.js
- ออกแบบและดูแลระบบคอมโพเนนต์ที่ใช้ร่วมกันหลายทีม ด้วย Tailwind CSS
- เขียนชุดทดสอบ (unit และ end-to-end) และปรับปรุงประสิทธิภาพหน้าเว็บ
- ทำงานร่วมกับดีไซเนอร์และทีม backend ผ่าน REST API

**คุณสมบัติ:** ประสบการณ์ Frontend 3 ปีขึ้นไป, เชี่ยวชาญ React และ TypeScript, มีประสบการณ์ด้านการทดสอบและ accessibility

## 2. Full-stack Developer — เหมาะปานกลาง

- **บริษัท:** ตัวอย่างซอฟต์แวร์ จำกัด (ตัวอย่าง)
- **สถานที่:** กรุงเทพมหานคร (ออฟฟิศ)

**รายละเอียดงาน**

ทีมผลิตภัณฑ์ต้องการ Full-stack Developer ที่ดูแลได้ทั้งหน้าบ้านและหลังบ้าน
- พัฒนาหน้าเว็บด้วย React และ TypeScript
- พัฒนา API ด้วย Node.js หรือ Python และออกแบบฐานข้อมูล PostgreSQL
- ดูแลการ deploy บน Docker และ CI/CD
- ดูแลระบบ production และตอบสนองเหตุขัดข้อง

**คุณสมบัติ:** ประสบการณ์ 3 ปีขึ้นไป, ถนัด backend อย่างน้อยหนึ่งภาษา, มีพื้นฐาน SQL และ DevOps

## 3. Data Engineer — เหมาะน้อย

- **บริษัท:** ตัวอย่างดาต้า จำกัด (ตัวอย่าง)
- **สถานที่:** กรุงเทพมหานคร (ไฮบริด)

**รายละเอียดงาน**

ต้องการ Data Engineer เพื่อสร้างและดูแลระบบข้อมูลของบริษัท
- ออกแบบ data pipeline แบบ batch และ streaming ด้วย Apache Spark และ Airflow
- สร้างและดูแล data warehouse บนคลาวด์ (เช่น BigQuery)
- เขียน SQL และ Python ที่ซับซ้อนเพื่อแปลงข้อมูลปริมาณมาก
- ดูแลคุณภาพข้อมูลและการ monitor pipeline

**คุณสมบัติ:** ประสบการณ์ data engineering 4 ปีขึ้นไป, เชี่ยวชาญ Spark, SQL และ Python

## 4. AI Engineer (LLM) — เหมาะมาก สำหรับ `cv-ai-engineer-th.pdf`

- **บริษัท:** ตัวอย่างอินเทลลิเจนซ์ จำกัด (ตัวอย่าง)
- **สถานที่:** กรุงเทพมหานคร (ไฮบริด)

**รายละเอียดงาน**

เรากำลังมองหา AI Engineer เพื่อพัฒนาผู้ช่วย AI สำหรับลูกค้าองค์กรในประเทศไทย
- ออกแบบและพัฒนาระบบ RAG ด้วย LLM สำหรับเอกสารภาษาไทยและอังกฤษ
- สร้างชุดประเมินคุณภาพคำตอบและลดคำตอบที่ไม่มีหลักฐานรองรับ
- พัฒนา API ด้วย Python และ FastAPI และ deploy ด้วย Docker และ Kubernetes บน AWS
- ทำงานร่วมกับทีมผลิตภัณฑ์ ติดตามค่าใช้จ่ายและเวลาตอบสนองของโมเดล

**คุณสมบัติ:** ประสบการณ์ด้าน Machine Learning หรือ AI 3 ปีขึ้นไป, เชี่ยวชาญ Python และ PyTorch, มีประสบการณ์ prompt engineering และ NLP ภาษาไทย, สื่อสารภาษาอังกฤษได้

## 5. Computer Vision Engineer — เหมาะปานกลาง สำหรับ `cv-ai-engineer-th.pdf`

- **บริษัท:** ตัวอย่างวิชั่น จำกัด (ตัวอย่าง)
- **สถานที่:** ชลบุรี (ออฟฟิศ)

**รายละเอียดงาน**

ต้องการ Computer Vision Engineer สำหรับระบบตรวจสอบคุณภาพสินค้าในโรงงาน
- ฝึกโมเดลตรวจจับวัตถุด้วย PyTorch และ OpenCV
- ปรับโมเดลให้ทำงานบนอุปกรณ์ edge แบบเรียลไทม์
- ดูแล data pipeline ภาพและการติดป้ายข้อมูล
- ทำงานร่วมกับวิศวกรโรงงานหน้างาน

**คุณสมบัติ:** ประสบการณ์ computer vision 3 ปีขึ้นไป, เชี่ยวชาญ PyTorch และ OpenCV, มีประสบการณ์ edge deployment
