# Webhooks and A2A Push Notifications (TOR FR-P06, FR-P04, FR-J05 push) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver signed, retried, dead-lettered HTTP push notifications for A2A task state changes, owner project webhooks, and saved-search digests, and complete A2A `tasks/list`.

**Architecture:**
- A database outbox (`webhook_deliveries`) is filled in the same transaction as each run event, through `services/runs.append_event`, and as each digest, through `services/saved_searches`.
- A `Webhooks` service owns signing, URL validation, enqueueing, delivery, retry/backoff, dead-letter, owner CRUD and A2A push configs.
- `WorkerSupervisor` runs a 2-second delivery loop and prunes history during housekeeping.
- The A2A handler and owner REST routes call the service. The settings UI gets a Webhooks section, and the saved-searches panel gets a push toggle.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy 2.1, Alembic (raw SQL), PostgreSQL 17, `httpx` (installed), `a2a-sdk` 1.2.1 (installed; `a2a.utils.push_url_validator.validate_push_notification_url`), React 19 + Vite + Tailwind 4, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-14-webhooks-design.md`

## Global Constraints

- Every outbound request is signed: `X-JSP-Signature: t=<unix seconds>,v1=<hex HMAC-SHA256(key, f"{t}." + body)>`. `X-JSP-Event` and `X-JSP-Delivery` are always sent. A2A requests also carry `X-A2A-Notification-Token: <token>`.
- Keys:
  - Owner webhooks use a server-generated `secrets.token_urlsafe(32)` secret. It is shown once and never returned again, logged, or placed in errors.
  - A2A uses the client token, which must be at least 16 characters.
- SSRF:
  - Only `https` URLs are accepted.
  - The host must pass `validate_push_notification_url`, both at registration and before every send.
  - Redirects are never followed.
  - `WEBHOOK_ALLOW_PRIVATE=1` lifts these rules (`http` and loopback allowed). It is for dev and tests only.
- Retry:
  - Retryable failures are network errors, timeouts, 5xx, 408 and 429.
  - Delays are `[1, 2, 4, 8, 16, 32, 64, 128]` minutes plus up to 10% jitter.
  - A delivery gets at most 8 attempts and is then `dead`.
  - Any other 4xx, and any 3xx, is `dead` immediately.
  - The request timeout is 10 s. Bodies are capped at 256 KB.
- Webhook events: `run.waiting_approval`, `run.needs_input`, `run.completed`, `run.failed`, `run.cancelled`, `digest.ready`. `ping` is sent only by "Send test".
- Limits: 5 webhooks per project, and 5 A2A push configs per task. Delivery history older than 30 days is pruned.
- The delivery loop runs every 2 s and sends at most 10 concurrently.
- Owner routes are owner-only, through `authorize(..., "webhook")`. A grant manages push configs only for runs whose `actor_scope == f"grant:{grant_id}"`. Revoked or expired grants get no deliveries.

## Review Focus

1. **The receiver is slow or hangs.** A delivery times out after 10 s, is retried later, and does not block other deliveries in the same batch, because sends run concurrently. Pinned by `test_timeout_is_retryable_and_does_not_block_batch` (Task 3).
2. **The process crashes mid-send.** A claimed row is leased for 5 minutes, so a restart neither re-sends it immediately nor loses it. Pinned by `test_claim_leases_rows` (Task 3).
3. **A grant is revoked after it registered a push config.** Already-queued rows die with `grant_revoked` and nothing more is queued. Pinned in Task 2 (enqueue) and Task 3 (send).
4. **One payload is huge.** A body over 256 KB is dead with `payload_too_large` and is never sent. Pinned by `test_oversized_payload_is_dead` (Task 3).
5. **A digest search has push on and email off.** It still runs on schedule and enqueues `digest.ready` without needing a mailer. Pinned by `test_push_only_digest_runs_without_mailer` (Task 2).

## Plan rulings against the spec

1. The run-status → A2A state mapping and the context id move into `services/a2a_state.py`, so A2A `tasks/get` and push payloads share one source.
2. Push payload state is derived from the run event type, not from `run.status`. `append_event` callers do not all update `run.status` before appending.
3. A saved search is due when `digest_enabled OR push_enabled`. Email goes out only if `digest_enabled`, and push only if `push_enabled`. Seen slugs are recorded when either channel was used. Unsubscribe still turns off email only.
4. A URL rejected at send time goes to `dead` with `last_error="blocked_url"`. A changed DNS answer is a configuration problem, not a transient failure.
5. A2A push-config responses never echo the token.
6. `WorkerSupervisor` gets two new guarded hooks: `deliveries`, run every 2 s in its own task, and `prune_deliveries`, run in housekeeping.

def sign(key: str, timestamp: int, body: bytes) -> str:

def backoff(attempts: int, rand: float) -> timedelta:
    """Delay before attempt ``attempts + 1``; ``rand`` in [0, 1] adds up to 10% jitter."""
    minutes = BACKOFF_MINUTES[min(attempts, MAX_ATTEMPTS) - 1]
    return timedelta(minutes=minutes * (1 + 0.1 * rand))

        parts = urlsplit(url)
    except ValueError:
        raise ServiceError("invalid_webhook_url") from None
    if allow_private():
        if parts.scheme not in {"http", "https"} or not parts.hostname:
            raise ServiceError("invalid_webhook_url")

def enqueue_for_run_event(db, run, event_type: str, now: datetime) -> int:
    """Queue A2A push and owner webhook deliveries for one run event, in the caller's transaction."""
    count = 0
    status = A2A_EVENT_STATUS.get(event_type)
    if status is not None:
        state, metadata = task_state(status)
        configs = db.scalars(select(A2APushConfig).join(Grant, Grant.id == A2APushConfig.grant_id).where(
            A2APushConfig.run_id == run.id, Grant.revoked_at.is_(None), Grant.expires_at > now)).all()
        for config in configs:
            update_payload = {"statusUpdate": {"taskId": str(run.id), "contextId": context_id(run.id),
                                               "status": {"state": state, "timestamp": _iso(now)}, "metadata": metadata}}
            _add(db, project_id=run.project_id, event_type=f"a2a.{status}", payload_for=lambda _id, p=update_payload: p,
                 now=now, push_config_id=config.id)
            count += 1
    event = RUN_EVENT_MAP.get(event_type)
    if event is not None:
        data = {"project_id": str(run.project_id), "run_id": str(run.id), "operation": run.operation,
                "status": A2A_EVENT_STATUS[event_type],
                "job_revision_id": str(run.job_revision_id) if run.job_revision_id else None}
        for endpoint in _endpoints(db, run.project_id, event):
            _add(db, project_id=run.project_id, event_type=event, now=now, endpoint_id=endpoint.id,
                 payload_for=lambda delivery_id: _envelope(delivery_id, event, now, data))
            count += 1
    return count

            "items": [{key: item.get(key) for key in DIGEST_ITEM_KEYS} for item in items]}

             payload_for=lambda delivery_id: _envelope(delivery_id, "digest.ready", now, data))
    return len(endpoints)

```python
LEASE = timedelta(minutes=5)
BATCH = 10
MAX_BODY = 256 * 1024
RETENTION = timedelta(days=30)
RETRYABLE = {408, 429}


def _classify(code: int | None, error: str | None) -> str:
    """'delivered', 'retry' or 'dead' for one HTTP attempt."""
    if error is not None:
        return "retry"
    if 200 <= code < 300:
        return "delivered"
    if code >= 500 or code in RETRYABLE:
        return "retry"
    return "dead"


class Webhooks:
    def __init__(self, sessions, *, timeout: float = 10.0, rand=random.random):
        self.sessions = sessions
        self.timeout = timeout
        self.rand = rand

    def _claim(self, now: datetime) -> list[dict]:
        with self.sessions.begin() as db:
            rows = db.execute(
                select(WebhookDelivery, WebhookEndpoint, A2APushConfig, Grant)
                .outerjoin(WebhookEndpoint, WebhookEndpoint.id == WebhookDelivery.endpoint_id)
                .outerjoin(A2APushConfig, A2APushConfig.id == WebhookDelivery.push_config_id)
                .outerjoin(Grant, Grant.id == A2APushConfig.grant_id)
                .where(WebhookDelivery.status == "pending", WebhookDelivery.next_attempt_at <= now)
                .order_by(WebhookDelivery.next_attempt_at).limit(BATCH)
                .with_for_update(skip_locked=True, of=WebhookDelivery)
            ).all()
            claimed = []
            for delivery, endpoint, config, grant in rows:
                delivery.next_attempt_at = now + LEASE  # lease: a crash mid-send does not re-send at once
                if endpoint is not None:
                    item = {"url": endpoint.url, "key": endpoint.secret, "token": None,
                            "blocked": None if endpoint.enabled else "endpoint_disabled"}
                else:
                    valid = grant is not None and grant.revoked_at is None and grant.expires_at > now
                    item = {"url": config.url, "key": config.token, "token": config.token,
                            "blocked": None if valid else "grant_revoked"}
                claimed.append({"id": delivery.id, "event": delivery.event_type, "payload": delivery.payload,
                                "attempts": delivery.attempts, **item})
            return claimed

    async def _send(self, client: httpx.AsyncClient, item: dict) -> tuple[int | None, str | None]:
        if item["blocked"]:
            return None, item["blocked"]
        body = json.dumps(item["payload"], separators=(",", ":"), ensure_ascii=False).encode()
        if len(body) > MAX_BODY:
            return None, "payload_too_large"
        try:
            await validate_url(item["url"])
        except ServiceError:
            return None, "blocked_url"
        headers = {"Content-Type": "application/json", "User-Agent": "ai-job-search-platform-webhooks/1",
                   "X-JSP-Event": item["event"], "X-JSP-Delivery": str(item["id"]),
                   "X-JSP-Signature": sign(item["key"], int(time.time()), body)}
        if item["token"]:
            headers["X-A2A-Notification-Token"] = item["token"]
        try:
            response = await client.post(item["url"], content=body, headers=headers)
        except httpx.TimeoutException:
            return None, "timeout"
        except httpx.HTTPError as exc:
            return None, type(exc).__name__[:200]
        return response.status_code, None

    def _record(self, item: dict, code: int | None, error: str | None, now: datetime) -> None:
        final_errors = {"endpoint_disabled", "grant_revoked", "blocked_url", "payload_too_large"}
        outcome = "dead" if error in final_errors else _classify(code, error)
        attempts = item["attempts"] + (0 if error in final_errors else 1)
        if outcome == "retry" and attempts >= MAX_ATTEMPTS:
            outcome = "dead"
        values = {"attempts": attempts, "last_status_code": code, "last_error": error}
        if outcome == "delivered":
            values.update(status="delivered", delivered_at=now)
        elif outcome == "dead":
            values.update(status="dead")
        else:
            values.update(next_attempt_at=now + backoff(attempts, self.rand()))
        with self.sessions.begin() as db:
            db.execute(update(WebhookDelivery).where(WebhookDelivery.id == item["id"]).values(**values))

    async def deliver_due(self, now: datetime | None = None) -> int:
        now = now or datetime.now(timezone.utc)
        claimed = await asyncio.to_thread(self._claim, now)
        if not claimed:
            return 0
        async with httpx.AsyncClient(follow_redirects=False, timeout=self.timeout) as client:
            results = await asyncio.gather(*(self._send(client, item) for item in claimed))
        for item, (code, error) in zip(claimed, results):
            await asyncio.to_thread(self._record, item, code, error, now)
        return len(claimed)

    def prune(self, now: datetime | None = None) -> int:
        now = now or datetime.now(timezone.utc)
        with self.sessions.begin() as db:
            return db.execute(delete(WebhookDelivery).where(
                WebhookDelivery.status.in_(("delivered", "dead")), WebhookDelivery.created_at < now - RETENTION)).rowcount

    async def prune_async(self) -> int:
        return await asyncio.to_thread(self.prune)
```

    async def set_push_config(self, actor, run_id: UUID, config_id: str, url: str, token: str) -> dict:
        if not isinstance(token, str) or not MIN_TOKEN <= len(token) <= 256 or len(config_id) > 128:
            raise ServiceError("invalid_push_config")
        await asyncio.to_thread(self._check_run, actor, run_id)
        try:
            await validate_url(url)
        except ServiceError:
            raise ServiceError("invalid_push_config") from None

        def upsert() -> dict:
            with self.sessions.begin() as db:
                run = db.scalar(select(Run).where(Run.project_id == actor.project_id, Run.id == run_id,
                                                  Run.actor_scope == f"grant:{actor.grant_id}").with_for_update())
                if run is None:
                    raise ServiceError("not_found")
                cid = config_id or uuid4().hex
                row = db.scalar(select(A2APushConfig).where(A2APushConfig.run_id == run_id, A2APushConfig.config_id == cid))
                if row is None:
                    count = db.scalar(select(func.count()).select_from(A2APushConfig).where(A2APushConfig.run_id == run_id))
                    if count >= MAX_PUSH_CONFIGS:
                        raise ServiceError("invalid_push_config")
                    row = A2APushConfig(project_id=run.project_id, run_id=run_id, grant_id=actor.grant_id, config_id=cid,
                                        url=url, token=token)
                    db.add(row)
                else:
                    row.url, row.token = url, token
                db.flush()
                return _config_view(row)
        return await asyncio.to_thread(upsert)

    def _check_run(self, actor, run_id: UUID) -> None:
        with self.sessions() as db:
            self._own_run(db, actor, run_id)

    def get_push_config(self, actor, run_id: UUID, config_id: str) -> dict:
        with self.sessions() as db:
            self._own_run(db, actor, run_id)
            row = db.scalar(select(A2APushConfig).where(A2APushConfig.run_id == run_id, A2APushConfig.config_id == config_id))
            if row is None:
                raise ServiceError("not_found")
            return _config_view(row)

        with self.sessions() as db:

            rows = db.scalars(select(A2APushConfig).where(A2APushConfig.run_id == run_id).order_by(A2APushConfig.created_at)).all()

    def list_runs(self, actor, *, statuses: set[str] | None, page_size: int, page_token: str) -> tuple[list[Run], str, int]:
        size = page_size if 1 <= page_size <= 50 else 20
        where = [Run.project_id == actor.project_id, Run.actor_scope == f"grant:{actor.grant_id}"]
        if statuses:
            where.append(Run.status.in_(statuses))
        with self.sessions() as db:
            total = db.scalar(select(func.count()).select_from(Run).where(*where))
            query = select(Run).where(*where)
            if page_token:
                try:
                    created, rid = json.loads(base64.urlsafe_b64decode(page_token.encode()))
                    created_at, last_id = datetime.fromisoformat(created), UUID(rid)
                except (ValueError, TypeError):
                    raise ServiceError("invalid_push_config") from None
                query = query.where((Run.created_at < created_at) | ((Run.created_at == created_at) & (Run.id < last_id)))

        token = ""
        if len(rows) > size:
            rows = rows[:size]
            last = rows[-1]
            token = base64.urlsafe_b64encode(json.dumps([last.created_at.isoformat(), str(last.id)]).encode()).decode()
        return list(rows), token, total

export function WebhookSettings({ projectId }: { projectId: string }) {
  const locale = useTranslation().i18n.language.startsWith('th') ? 'th' : 'en';
  const c = copy[locale];
  const base = `/projects/${projectId}/webhooks`;
  const hooks = useResource<WebhookView[]>(base);
  const deliveries = useResource<WebhookDeliveryView[]>(`${base}/deliveries`);
  const [url, setUrl] = useState('');
  const [events, setEvents] = useState<WebhookEvent[]>([]);
  const [secret, setSecret] = useState<string | null>(null);
  const [message, setMessage] = useState<{ ok: boolean; text: string } | null>(null);
  const [busy, setBusy] = useState(false);
  const [deleting, setDeleting] = useState<WebhookView | null>(null);
  const when = new Intl.DateTimeFormat(locale === 'th' ? 'th-TH' : 'en-US', { dateStyle: 'short', timeStyle: 'short' });

  async function run(action: () => Promise<unknown>) {
    if (busy) return;
    setBusy(true); setMessage(null);
    try { await action(); hooks.reload(); deliveries.reload(); }
    catch (error) { setMessage({ ok: false, text: (error instanceof ApiError && c.errors[error.code]) || c.error }); }
    finally { setBusy(false); }
  }
  async function add() {
    await run(async () => {
      const created = await sendJson<WebhookView & { secret: string }>(base, 'POST', { url: url.trim(), events });
      setSecret(created.secret); setUrl(''); setEvents([]);
    });
  }

  if (hooks.status === 'loading' && !hooks.data) return <LoadingBlock label={c.loading} />;
  return <SectionCard title={c.title} description={c.description}>
    {secret && <div className="grid gap-2 rounded-md border border-warning p-3">
      <p className="text-sm font-semibold">{c.secretTitle}</p>
      <code className="break-all rounded bg-muted p-2 text-sm">{secret}</code>
      <p className="text-sm text-warning">{c.secretOnce}</p>
      <div><Button variant="outline" onClick={() => setSecret(null)}>{c.secretDone}</Button></div>
    </div>}
    <form className="grid gap-4" onSubmit={event => { event.preventDefault(); if (url.trim() && events.length) void add(); }}>
      <Field id="webhook-url" label={c.url} hint={c.urlHint}>
        <Input id="webhook-url" type="url" inputMode="url" maxLength={2048} value={url} onChange={event => setUrl(event.target.value)} required />
      </Field>
      <fieldset className="grid gap-1"><legend className="mb-1 text-sm font-medium">{c.events}</legend>
        <div className="grid gap-1 sm:grid-cols-2">{EVENTS.map(event => <label key={event} className="flex min-h-10 items-center gap-2 text-sm">
          <input type="checkbox" checked={events.includes(event)} onChange={e => setEvents(prev => e.target.checked ? [...prev, event] : prev.filter(x => x !== event))} />{c.labels[event]}
        </label>)}</div>
      </fieldset>
      {message && <Notice ok={message.ok}>{message.text}</Notice>}
      <div><Button type="submit" disabled={busy || !url.trim() || !events.length}>{c.add}</Button></div>
    </form>
    <p className="text-sm text-muted-foreground">{c.verify}</p>
    {(hooks.data ?? []).length === 0 ? <p className="text-sm text-muted-foreground">{c.empty}</p> :
      <ul className="grid gap-2">{(hooks.data ?? []).map(hook => <li key={hook.id} className="grid min-w-0 gap-2 rounded-md bg-muted/40 p-3 sm:grid-cols-[minmax(0,1fr)_auto] sm:items-center">
        <div className="min-w-0">

          <p className="text-xs text-muted-foreground">{hook.events.map(e => c.labels[e]).join(' · ')}</p>

            <td className="px-2 py-1">{c.status[d.status]}</td>

}
