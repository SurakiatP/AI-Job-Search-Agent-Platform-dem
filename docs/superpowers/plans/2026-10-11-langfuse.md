# Langfuse Run Tracing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Self-host Langfuse 4.56.0 on loopback behind a compose profile, and send the app's existing metadata-only OTel run spans to it.

**Architecture:**
- **Infrastructure:** Six new compose services share a private network under profile `langfuse`. Only `langfuse-web` publishes `127.0.0.1:53000`.
- **`scripts/local_infra.py`:**
  - Generates every secret (0600), the derived ClickHouse and Valkey config files, and the gitignored root `CREDENTIALS.md`.
  - Turns the profile on when `LANGFUSE_HOST` is set.
- **App:** `integrations/tracing.py` builds an OTLP exporter for Langfuse from `LANGFUSE_HOST` and the project key files. `llm.round` spans gain `gen_ai.*` attributes.

**Tech Stack:**
- Docker Compose.
- Python 3.12. `local_infra.py` uses only the stdlib.
- opentelemetry-sdk and opentelemetry-exporter-otlp-proto-http 1.45.1, both already locked.
- pytest.

  - `langfuse/langfuse-worker:4.56.0@sha256:3f7571ff3a725ebdcdf4c35e06bdf8c3f8325770691c673793ad61b328265e13`

- **Ports:** only `langfuse-web` publishes a port: `127.0.0.1:${CORE02_LANGFUSE_PORT:-53000}:3000`.
- **Secrets:**
  - No secret value appears in `infra/compose.yaml`, `.env`, `.env.example`, logs, stdout or test output.

- **Off by default:** with `LANGFUSE_HOST` empty, `local_infra.py start` brings up exactly today's services.

  - `CLICKHOUSE_PASSWORD_FILE` is **ignored**, and user `default` is open without a password.
  - A bind-mounted `users.d/*.xml` with `password_sha256_hex` and `<default remove="remove"/>` works: it locks out `default`, and user `langfuse` can create tables.
  - Bind sources must sit under a Docker-shared path such as `~/.cache/...`. `/private/tmp` is not shared and mounts silently as nothing.

## Review Focus

1. **Keys missing or unreadable.** `LANGFUSE_HOST` is set, but the key files are missing, empty or group-readable, for example before the first `start`. Expected: tracing is off, one warning is logged, and the app starts normally. *Pinned in Task 3.*
2. **Messy host value.** `LANGFUSE_HOST` has a trailing slash or whitespace. Expected: the endpoint is exactly `<host>/api/public/otel/v1/traces`. *Pinned in Task 3.*
3. **Langfuse turned off after use.** The owner clears `LANGFUSE_HOST` after Langfuse has run. Expected: `stop` still stops the Langfuse containers, and `start` no longer starts them. *Pinned in Task 1.*
4. **Upgrading an existing private dir.** The dir already holds the LiteLLM and storage secrets. Expected: only the new Langfuse files are added, and every existing file stays byte-identical. *Pinned in Task 1.*
5. **Bad existing `CREDENTIALS.md`.** It already exists as a symlink, or with mode 0644. Expected: a symlink is refused and its target is untouched. Otherwise the file ends at 0600. *Pinned in Task 1.*

Tasks 1 and 3 touch disjoint files and can run in parallel. Task 2 needs Task 1. Task 4 needs all three.

def _write_owner_only(path: Path, text: str) -> None:
    """Create or replace a 0600 file without following a symlink."""
    descriptor = os.open(path, os.O_WRONLY | os.O_CREAT | os.O_TRUNC | os.O_NOFOLLOW, 0o600)
    with os.fdopen(descriptor, "w", encoding="utf-8") as output:
        os.fchmod(output.fileno(), 0o600)
        output.write(text)
        output.flush()
        os.fsync(output.fileno())


def _read_secret(private_dir: Path, name: str) -> str:
    return (private_dir / name).read_text(encoding="utf-8").strip()


def _clickhouse_users(password: str) -> str:
    """users.d override: the pinned distroless image ignores CLICKHOUSE_PASSWORD_FILE and leaves `default` open."""
    digest = hashlib.sha256(password.encode("utf-8")).hexdigest()
    return (
        "<clickhouse>\n  <users>\n    <default remove=\"remove\"/>\n    <langfuse>\n"
        f"      <password_sha256_hex>{digest}</password_sha256_hex>\n"
        "      <networks><ip>::/0</ip></networks>\n      <profile>default</profile>\n"
        "      <quota>default</quota>\n      <access_management>1</access_management>\n"
        "    </langfuse>\n  </users>\n</clickhouse>\n"
    )


def ensure_credentials(private_dir: Path) -> None:
    for name in (*SECRET_NAMES, *DERIVED_NAMES):
        path = private_dir / name
        if path.exists() or path.is_symlink():
            _check_secret_file(path)
    for name, generate in SECRETS.items():
        path = private_dir / name
        if path.exists():
            continue
        descriptor = os.open(path, os.O_WRONLY | os.O_CREAT | os.O_EXCL, 0o600)
        with os.fdopen(descriptor, "w", encoding="utf-8") as output:
            output.write(generate())
            output.write("\n")
            output.flush()
            os.fsync(output.fileno())
    # Derived from the secrets above, so rewriting keeps them in sync and is byte-identical when unchanged.
    _write_owner_only(private_dir / "langfuse-clickhouse-users.xml",
                      _clickhouse_users(_read_secret(private_dir, "langfuse-clickhouse-password")))
    _write_owner_only(private_dir / "langfuse-valkey.conf",
                      f"requirepass {_read_secret(private_dir, 'langfuse-redis-password')}\nmaxmemory-policy noeviction\n")
    # The seed container writes the app key into this bind-mounted file; it must exist first.
    app_key = private_dir / APP_KEY_FILE
    if app_key.exists() or app_key.is_symlink():
        _check_secret_file(app_key)
    else:
        os.close(os.open(app_key, os.O_WRONLY | os.O_CREAT | os.O_EXCL, 0o600))
```

def write_credentials_summary(private_dir: Path, langfuse: bool, target: Path = ROOT / "CREDENTIALS.md") -> Path:

        raise ConfigurationError("credentials_summary_symlink")
    s = lambda name: _read_secret(private_dir, name)  # noqa: E731
    port = lambda name, default: os.environ.get(name) or default  # noqa: E731

    text = f"""# Local credentials — DO NOT COMMIT (gitignored, mode 0600)

Regenerated by `scripts/local_infra.py start` from `{private_dir}`; the files there are the source of truth.

## Owner app
- URL: http://127.0.0.1:8000 (share listener :8001 when enabled)
- Login: one-use bootstrap URL printed by the launcher (no stored password)

## PostgreSQL (app data)
- Address: 127.0.0.1:{port('CORE02_POSTGRES_PORT', '55432')}, database `jobsearch_platform_core02`
- User: `{s('postgres-user')}`
- Password: `{s('postgres-password')}`

## MinIO (object store)
- API: http://127.0.0.1:{port('CORE02_MINIO_PORT', '59000')}

def read_private_file(private_dir: Path, name: str) -> str | None:
    """Stripped contents of an owner-only regular file in the private dir, else None."""
    path = private_dir / name
    try:
        if path.is_symlink() or not path.is_file() or stat.S_IMODE(path.stat().st_mode) & 0o077:
            return None
        return path.read_text(encoding="utf-8").strip() or None
    except OSError:
        return None

def _langfuse_exporter() -> OTLPSpanExporter | None:
    """OTLP exporter for the self-hosted Langfuse, or None until its project keys exist."""
    host = os.environ.get("LANGFUSE_HOST", "").strip().rstrip("/")
    private_dir = default_private_dir()
    public = read_private_file(private_dir, "langfuse-public-key")
    secret = read_private_file(private_dir, "langfuse-secret-key")
    if not (host and public and secret):
        logger.warning("langfuse_keys_unavailable")
        return None
    token = base64.b64encode(f"{public}:{secret}".encode()).decode()
    return OTLPSpanExporter(endpoint=f"{host}/api/public/otel/v1/traces", headers={"Authorization": f"Basic {token}"})


def configure() -> bool:
    """Install one OTLP HTTP exporter: an explicit OTLP endpoint wins, else Langfuse; a no-op without either."""
    explicit = bool(os.environ.get("OTEL_EXPORTER_OTLP_ENDPOINT"))
    if not explicit and not os.environ.get("LANGFUSE_HOST", "").strip():
        return False
    if isinstance(trace.get_tracer_provider(), TracerProvider):
        return True
    exporter = OTLPSpanExporter() if explicit else _langfuse_exporter()
    if exporter is None:
        return False
    provider = TracerProvider(resource=Resource.create({"service.name": SERVICE_NAME}))
    provider.add_span_processor(BatchSpanProcessor(exporter))
    trace.set_tracer_provider(provider)
    return True


def llm_round(*, run_id: Any, model: str | None, latency_ms: int, input_tokens: int | None, output_tokens: int | None) -> None:
    """One llm.round span that Langfuse renders as a generation. Metadata only."""
    record("llm.round", model=model, latency_ms=latency_ms, input_tokens=input_tokens,
           output_tokens=output_tokens, run_id=run_id,
           **{"gen_ai.request.model": model, "gen_ai.usage.input_tokens": input_tokens,
              "gen_ai.usage.output_tokens": output_tokens, "langfuse.observation.type": "generation"})
```
